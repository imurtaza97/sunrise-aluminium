# 🌅 Sunrise Aluminium Website

Live Website: https://www.sunrisealuminium.in/

## 📌 Overview

A production-ready business website built for **Sunrise Aluminium**, designed to showcase services and capture customer inquiries efficiently.

This project focuses on providing a **simple, fast, and conversion-focused online presence** for a local business.

---

## 🚀 Features

### 🖥️ Frontend (Client Website)

* Modern responsive single-page design
* Service showcase section
* Contact form for customer inquiries
* Fast loading and SEO-friendly structure

### 🔐 Admin Panel

* Secure admin interface
* View incoming contact inquiries
* Real-time updates using socket connection

### 🔔 Live Notifications

* Instant notification system for new leads
* Built using a separate socket server:
  👉https://github.com/imurtaza97/sunrise-socket

---

## 🛠️ Tech Stack

* Frontend: Next.js
* Backend: API Routes (Next.js)
* Real-time: Socket-based communication
* Deployment: Vercel
